# Scanner Usage Guide - Dual Scanner System

**Last Updated:** 2025-11-07

Your Little Library now has TWO ways to add books via scanning. Here's when to use each:

---

## 📸 **QUICK SCAN** (New - ScanToAddBook)

**Button Location:**
- Desktop: **"Scan Book"** button (emerald/teal gradient) in library header
- Mobile: **Camera FAB** (emerald circle, floating above + button)

**When to Use:**
- ✅ Adding 5-20 books quickly
- ✅ New books with good ISBN data
- ✅ You trust Google Books info
- ✅ Books in good condition (default)
- ✅ Speed over control
- ✅ Bulk scanning session

**Flow:**
1. Click "Scan Book"
2. Camera opens immediately
3. Point at barcode
4. See preview (cover, title, author)
5. Select condition
6. Click "Add to Library"
7. DONE! (2 seconds)

**Best For:** Your wife scanning her new book purchases quickly

---

## 📝 **SCAN + EDIT** (Original - AddBookModal Scanner)

**Button Location:**
- Desktop: **"Add Book"** button (mood-colored) in library header
- Mobile: **+ FAB** (mood-colored circle, bottom floating button)

**When to Use:**
- ✅ Need to add notes/details
- ✅ Book has missing/wrong data
- ✅ Want to review before adding
- ✅ Adding custom genre
- ✅ Rare/old books
- ✅ Multiple editions need clarification

**Flow:**
1. Click "Add Book"
2. Form opens
3. Click "Scan" button (next to ISBN field)
4. Scanner opens
5. Scans → auto-fills form
6. **EDIT any fields you want**
7. Add notes, select genre, etc.
8. Submit

**Best For:** Careful cataloging, special books, when data needs correction

---

## 🎯 **Quick Reference:**

| Scenario | Use This Scanner |
|----------|-----------------|
| "I just got 10 new books from the bookstore" | **Quick Scan** |
| "I need to add my entire collection fast" | **Quick Scan** |
| "This is a rare first edition I want to note" | **Scan + Edit** |
| "Google has the wrong year for this book" | **Scan + Edit** |
| "I want to add personal notes about this book" | **Scan + Edit** |
| "I'm at a used book sale scanning lots" | **Quick Scan** |
| "This book doesn't have an ISBN" | **Scan + Edit** (use manual entry) |

---

## 💡 **Pro Tips:**

1. **Batch Scanning:** Use Quick Scan for speed, then edit books later if needed via the edit button
2. **Poor Lighting:** Both scanners work better in good light
3. **No ISBN:** Some old books don't have ISBN - use Scan + Edit for manual entry
4. **Wrong Data:** If Quick Scan gets bad data, you can edit the book after adding
5. **Multiple People:** Friends can use Quick Scan without training - it's foolproof

---

## 🔄 **Can I Switch?**

Yes! You can:
- Quick Scan a book → Edit it later (click edit button on book card)
- Use Scan + Edit for maximum control
- Mix and match based on your mood

---

**Bottom Line:**
- **Quick Scan** = Fast and easy
- **Scan + Edit** = Control and precision

Both use the same camera technology (Quagga) and Google Books API - just different workflows!
